How to use the editor

Drag nodes onto the canvas, connect an output at the bottom of one node to the input at the top of another, and edit the selected node in the Properties panel. Drag the blank canvas to pan and use the zoom controls to navigate.

Hold Shift and drag across the canvas to select an area. Ctrl/Cmd-click adds individual nodes to the selection. Selected nodes can be moved together.

Right-click a node or the canvas for quick actions. Use Preview to test the current interactive story before exporting HTML. Save JSON to keep an editable project copy.

Node reference

Start
The entry point of the story. Connect its bottom output to the first node.
Text
Displays text, then continues through its output.
Buttons
Shows choices. Each bottom output corresponds to a choice.
Image
Displays an image and continues to the next node.
JavaScript
Runs custom JavaScript, then continues.
Random Chance
Selects one of its bottom outputs at random.
User Input
Asks the player for text and saves it to a variable.
Logic Check
Branches through its first output when true and second output when false.

Keyboard: Ctrl/Cmd+Z undoes the last change. Ctrl/Cmd+Shift+Z redoes it.
